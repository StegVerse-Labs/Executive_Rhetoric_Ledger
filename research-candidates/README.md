# Research Candidates

This directory contains evidence-bounded ERL research candidates. Candidate status records source material, claims, uncertainty, and required discriminators without promoting source assertions into verified findings.

Candidate activation is enforced by `scripts/validate_research_candidate_activation.py`. Directory documentation such as this `README.md` is explicitly excluded from candidate discovery. New candidate groups admitted after the original monolithic registry rollout may be added through validated `coordination/research-candidate-activation-registry.overlay.*.json` files, which are combined with the canonical base registry and checked for duplicate IDs, duplicate candidate paths, missing ownership, missing next actions, missing terminal conditions, stale paths, and unauthorized candidate-layer findings/publication.
